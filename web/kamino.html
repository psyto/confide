The rule, in four lines of Kamino's source

A reserve refuses a token account that can hold value confidentially. The same check runs on the holder's own account, not only on Kamino's vault — so it gates the counterparty, and it gates deposit, borrowing and both sides of liquidation alike.

What it would take

A reserve that can value a balance it cannot read needs two things. Confide has parts of both, and the parts it does not have are named here rather than skipped.
neededstate
A floor, proved — not the balance, a lower bound on it, so a reserve can value the position at q_min × price and ignore the rest runs Solana's ZK program checks it; the escrow's own ciphertext is bound in
Custody that survives the holder — a proved floor is worthless if the holder can withdraw below it afterwards runs origination verifies the escrow's owner is the loan PDA before recording anything
Re-proving — a floor proved once is a floor at one moment, and a reserve marks continuously not built either on a schedule the reserve enforces, or the trigger absorbs the staleness
Liquidation hand-off — the seizure has to fit inside Kamino's liquidation instruction, not beside it not built de-shielding is disabled; finishing it is not the work, reaching a liquidator is
An exemption — the escrow is PDA-owned and confidential, so it fails :187 and :201 by design Kamino's call the alternative is making the value public at deposit, which gives up the point
